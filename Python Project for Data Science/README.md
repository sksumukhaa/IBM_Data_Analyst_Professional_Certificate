# Python Project for Data Science

## Project Scenario

In this project, you will assume the role of a **Data Scientist / Data Analyst** at a startup investment firm that helps clients make informed stock market investments. Your objective is to collect financial data, including historical stock prices and quarterly revenue reports, from multiple sources using Python libraries and web scraping techniques. The collected data is then visualized to identify key trends and patterns.

---

## Final Assignment – Data Extraction with Python

In this assignment, you will extract historical stock market data using the **yfinance** Python library.

### Objectives

- Retrieve historical stock price data using the **yfinance** library.
- Process and prepare the extracted data for analysis.

---

## Final Assignment – Web Scraping

In this assignment, you will use **Beautiful Soup** to scrape financial data from web pages.

### Objectives

- Extract historical stock data through web scraping.
- Collect financial information from publicly available web pages.

---

## Final Assignment

In the final assignment, you will combine data extracted using both **yfinance** and **Beautiful Soup** to analyze the stock performance of **Tesla (TSLA)** and **GameStop (GME)**.

### Objectives

- Extract historical stock prices using **yfinance**.
- Scrape quarterly revenue data using **Beautiful Soup**.
- Visualize stock prices and revenue trends using Python.
- Analyze the relationship between stock performance and company revenue.
