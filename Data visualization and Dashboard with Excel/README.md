# Excel Data Visualization

## Assignment Scenario

As a **Regional Manager** for a chain of car dealerships, your objective is to analyze dealership performance by creating visualizations that provide insights into vehicle sales and profitability. Using Excel, you will develop charts and dashboards to compare key performance indicators (KPIs) across dealers, models, and time periods.

### Key Performance Indicators (KPIs)

Create visualizations for the following metrics:

- **Quantity Sold by Dealer ID**
- **Profit by Date and Model**
- **Profit by Year and Dealer ID**
- **Profit of Hudson Models by Dealer ID**
