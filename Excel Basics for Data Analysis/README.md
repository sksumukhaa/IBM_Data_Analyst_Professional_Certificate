# Excel Basics for Data Analysis

## Assignment Scenario 1

In this final assignment, you will take on the role of a newly hired **Junior Data Analyst** in a local government office. Your task is to import inventory data related to the department's fleet of vehicles. The data is provided in **CSV (Comma-Separated Values)** format and requires cleaning before it can be analyzed effectively.

### Tasks to Perform

- Convert the CSV file to an **XLSX** workbook.
- Adjust column widths for better readability.
- Remove empty rows.
- Remove duplicate records.
- Correct spelling errors.
- Remove unnecessary whitespace.
- Merge department names split across two columns using **Flash Fill**.
- Save the cleaned workbook as:
  ```
  Montgomery_Fleet_Equipment_Inventory_FA_PART_1_END.xlsx
  ```

## Assignment Scenario 2

After importing and cleaning the fleet inventory data, your next task is to organize and analyze the dataset. You will use **Pivot Tables** to summarize the data and prepare it for visualization in a dashboard and a data analysis report.

### Tasks to Perform

- Format the dataset as an Excel Table.
- Calculate **SUM, AVERAGE, MIN, MAX, and COUNT**.
- Create a Pivot Table.
- Sort the Pivot Table in descending order based on the **Sum of Equipment Count**.
- Create two additional Pivot Tables similar to the first one.
- Analyze the data using the Pivot Tables.
- Save the completed workbook as:
  ```
  Montgomery_Fleet_Equipment_Inventory_FA_PART_2_END.xlsx
  ```
