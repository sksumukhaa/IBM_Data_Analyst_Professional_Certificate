# Data Analyst Capstone Project

## Module 1 – Data Collection

Learn techniques to gather data from multiple sources for analysis.

### Topics Covered

- Collecting Data Using APIs
- Collecting Data Using Web Scraping
- Exploring Data

---

## Module 2 – Data Wrangling

Prepare and clean raw data to ensure accuracy and consistency before analysis.

### Topics Covered

- Finding Missing Values
- Imputing Missing Values
- Finding Duplicates
- Removing Duplicates
- Normalizing Data

---

## Module 3 – Exploratory Data Analysis (EDA)

Perform statistical analysis to identify patterns, relationships, and anomalies within the dataset.

### Topics Covered

- Distribution Analysis
- Outlier Detection
- Correlation Analysis

---

## Module 4 – Data Visualization

Create visual representations to effectively communicate insights from the data.

### Topics Covered

- Visualizing Data Distribution
- Visualizing Relationships
- Composition of Data
- Comparison of Data

---

## Module 5 – Dashboard Development

Build an interactive dashboard to present key insights and performance metrics.

### Topics Covered

- Creating Dashboards with IBM Cognos Analytics

---

## Module 6 – Present Your Findings

Communicate analytical insights and recommendations through a structured presentation.

### Topics Covered

- Final Project Presentation
